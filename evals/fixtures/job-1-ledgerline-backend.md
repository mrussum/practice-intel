# Senior Backend Engineer
Company: Ledgerline

Ledgerline builds double-entry accounting infrastructure for fintechs. You will own core services that move money, so correctness and reliability matter more than novelty.

What you'll do
- Design and run the services behind our ledger and payouts APIs.
- Improve reliability, observability and performance of high-volume transaction paths.
- Help grow a small, senior backend team.

Requirements
- TypeScript: 4+ years building production backend services
- Node.js: deep experience with services under sustained load
- PostgreSQL: schema design, query tuning and safe migrations
- AWS: running production workloads (ECS, RDS or similar)
- Terraform: infrastructure as code for all environments
- Mentoring: supporting and reviewing the work of other engineers

Nice to have
- Kafka: event-driven architectures
- Payments: experience in payments or financial systems
- GraphQL: designing public APIs

Benefits
Remote-first within the UK, 30 days holiday, learning budget.
